# Mauve & Charcoal Prestige Color Palette (2026-02-11)

## Overview
Implemented the "Mauve & Charcoal Prestige" visual identity across the entire website. This update shifts the aesthetic towards a more sophisticated, high-contrast, yet soft professional look suitable for a premium UGC creator.

## Core Palette Applied
- **Nordic White (#F9F9F9)**: Primary background for a soft, premium canvas.
- **Snow (#FFFFFF)**: Used for cards and secondary surfaces to create depth.
- **Charcoal (#1A1A1A)**: The "Prestige" anchor for headings, primary actions, and structural elements.
- **Mauve (#BC6C84)**: Sophisticated accent for branding, highlights, and active states.
- **Stone (#E5E5E5)**: Subtle structural color for borders and dividers.

## Key CSS & UI Updates
- **Typography**:
  - Headings defaulted to **Charcoal**.
  - Body copy set to **Charcoal at 50% opacity** for an elegant, non-heavy reading experience.
  - Section labels and luxury accents updated to **Mauve**.
  - Ultra-wide letter spacing (`0.22em`) for editorial tags.
- **Components**:
  - **Buttons**: Primary buttons now feature a Charcoal base with a Mauve hover effect. Secondary buttons use a Charcoal/60 text and Stone borders.
  - **Glassmorphism**: Updated to 60% white opacity with a 12px blur for a cleaner "frosted" look.
  - **Hero Ambient**: Added a high-end radial gradient glow at the top right using fading Mauve.
  - **Selection**: Custom text selection set to Charcoal background with white text.
- **Structural**:
  - Simplified background logic by removing complex gradients in favor of the Nordic White base.
  - Refined dividers and structural rules with lowered opacity Stone colors.

## Aesthetic Goal
The design now feels intentionally curated, avoiding generic layouts in favor of a "Nordic Femme Luxe" palette that communicates good taste, luxury, and prestige without being "tacky."
