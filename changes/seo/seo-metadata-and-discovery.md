# SEO, Metadata, and Discovery Baseline

## Summary
This condenses the metadata and discovery work that prepared the site for the later SEO split. The focus was on real social/link-preview wiring, favicon cleanup, market-positioning copy, llms/robots alignment, canonical host normalization, and stronger global/local balance in metadata.

## Consolidated outcomes
1. Social profiles and link-preview metadata were wired to real destinations, making messaging-app previews and social sharing consistent.
2. Favicon and SERP signals were cleaned up so the site presents a more stable branded appearance in Google and browser surfaces.
3. Marketing copy broadened from a narrower local framing into bilingual global positioning, with services and metadata aligned around UGC, spokesperson, and brand-ambassador work.
4. Canonical host handling and metadata spacing were normalized before the later ES/EN homepage split.
