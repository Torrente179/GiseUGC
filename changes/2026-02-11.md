# 2026-02-11 - Interactive Portfolio and Service Motion Updates

## Summary
Added three new interactive showcase features to the website:
- A short-video portfolio reel carousel.
- A hover-activated collage box that plays/pauses video clips.
- A slow, corner-to-corner moving services carousel with service titles.

## What Was Changed
1. Portfolio reel section
- Added a horizontal, scrollable short-video carousel with navigation arrows.
- Added muted autoplay preview videos with category/title overlays.
- Kept the existing portfolio filtering and modal behavior.

2. Interactive collage section
- Added an image/video collage panel with layered cards.
- Implemented hover/focus behavior to start playback for all collage videos.
- Implemented mouse-leave/blur behavior to pause and reset all collage videos.
- Added idle/playing visual state hints.

3. Services moving carousel
- Added a new section under Services with repeated service cards.
- Implemented continuous marquee movement.
- Added a subtle corner-to-corner drift animation for the carousel group.

4. Global animation styling
- Added `services-marquee` and `corner-drift` keyframes.
- Added reduced-motion fallback (`prefers-reduced-motion`) to disable motion when requested by user/system preferences.

5. Localization updates
- Added new translation keys in English and Spanish for:
  - Portfolio reel texts and ARIA labels.
  - Collage section texts, points, CTA, and play-state hints.
  - Services moving carousel title and subtitle.
